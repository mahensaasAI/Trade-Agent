# Y Square brand assets

Everything here is generated by `workflows/gen_brand.js` (run `npm run gen:brand`). The lettering is
converted to outlines, so the files render identically everywhere and need no font installed.

## Files

| File | Use |
| --- | --- |
| `ysquare-mark.svg` | The Y² mark, rounded square, transparent corners. Master file - scale to any size. |
| `ysquare-mark-square.svg` | Same mark with square corners, for places that add their own rounding (iOS, Android, some ad platforms). |
| `ysquare-mark-1024/256/180/64/32.png` | Raster mark. 1024 for app stores and press, 180 for Apple touch icon, 32 for favicon. |
| `ysquare-mark-square-1024.png` | Square-corner raster, same sizes rule. |
| `ysquare-lockup-light.svg` / `-light-1600.png` | Mark + "Y Square WORKPLACE" for light backgrounds. |
| `ysquare-lockup-dark.svg` / `-dark-1600.png` | Same lockup for dark backgrounds. |
| `ysquare-card-1200x630.png` | Open Graph / link preview / display ad, no URL. |
| `ysquare-card-1200x630-url.png` | Same card with ysquareai.com on it. |
| `ysquare-card-1080x1080.png` | Square card for Instagram and LinkedIn. |

PNGs have transparent backgrounds except the cards.

## Colours

| Token | Hex | Where |
| --- | --- | --- |
| Indigo | `#4f46e5` | Gradient start, primary buttons, links |
| Violet | `#7c3aed` | Gradient middle |
| Pink | `#db2777` | Gradient end |
| Amber | `#fbbf24` | The `2`, accents |
| Ink | `#0d1220` | Wordmark on light backgrounds |
| Paper | `#ffffff` | Wordmark on dark backgrounds |

The mark's gradient runs top-left indigo to bottom-right pink at 135 degrees.

## Using it

- Keep clear space of at least half the mark's width on every side.
- Smallest legible sizes: 24px for the mark, 120px wide for the lockup.
- On photos or busy backgrounds use the dark lockup over a dimmed area, never the light one.
- Do not recolour the mark, stretch it, add a drop shadow to the wordmark, or rebuild the lockup
  with a different font - use `ysquare-lockup-*.svg` as-is.
